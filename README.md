# making-fly-play-chess

No better way to use fly neurons, then to make them play chess!

So, this project, for someone who did not understand, is using fly's neurons from https://github.com/philshiu/Drosophila_brain_model , and trains them to play chess using reinforcement learning.

If you just want to play, then use the ipynb inference file, upload it to google colab, and click 'Run All'. scroll down, and use the gui/

this project uses https://github.com/philshiu/Drosophila_brain_model for fly's brains.
